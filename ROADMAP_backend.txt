Day 3: Database with SQLite + User Authentication
We have three base tables (models): Users, Files and Jobs
Each link to each other, so that one can do OOP, e.g. my_user.user.file
They inherit a basic model from database.py
For autentication we use FastAPIUsers, which can handle:

-User registration
-User login
-Password hashing
-JWT tokens (secure login tokens)

Upon error "databaase is blocked", delete the current database in backend/database.db
