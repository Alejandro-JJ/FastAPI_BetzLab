# StreamLitTFM
This is a GUI for 2D traction force microscopy.
## Instructions
For development:  
Clone the repository
```
git clone git@gitlab.gwdg.de:betzlab/traction-force-microscopy/steamlittfm.git
```
Recreate the environment
```
conda create -f env.yml -n streamlit
```
Activate the application
```
streamlit run stream.py
```
Follow instructions in GUI for traction force microcsopy.
