# Traction force utilities
Lorems

## Development

Clone into project:
```
conda clone git@gitlab.gwdg.de:betzlab/traction-force-microscopy/traction-force-utilities.git
```
cd into project.\
recreate conda environment:
```
conda env create -f env.yml
```
Start coding

## Installation and usage
Install with pip:
```
pip install git+ssh://git@gitlab.gwdg.de/betzlab/traction-force-microscopy/traction-force-utilities.git@v0.0.3
```

Open python and ``import traction_force``.
